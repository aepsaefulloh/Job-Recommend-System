📚 Tentang K-Means Clustering

K-Means adalah algoritma pembelajaran unsupervised yang mempartisi data ke dalam k cluster berdasarkan kesamaan fitur. Analisis ini mensegmentasikan pencari kerja ke dalam {{ optimal_k }} kelompok berbeda berdasarkan IPK mereka (nilai_rata), ekspektasi gaji (gaji), dan total pengalaman kerja (lama_kerja_2).

📉 Penjelasan Metode Elbow

Metode Elbow membantu menentukan jumlah cluster optimal dengan memplot inertia (jumlah kuadrat dalam cluster) terhadap jumlah cluster. Titik "siku" menunjukkan di mana menambah lebih banyak cluster memberikan hasil yang tidak signifikan. Untuk dataset ini, k={{ optimal_k }} adalah pilihan optimal, ditandai dengan garis putus-putus merah.

💡 Interpretasi Cluster

Visualisasi clustering menunjukkan pencari kerja tersebar ke dalam {{ optimal_k }} segmen berbeda:

  • Cluster Merah: Satu segmen pencari kerja
  • Cluster Hijau Terang: Segmen lain dengan karakteristik berbeda
  • Cluster Biru: Segmen ketiga dengan pola unik
  • Bintang Kuning: Mewakili centroid cluster (pusat)

Cluster ini mewakili pengelompokan alami dalam data, yang dapat berguna untuk rekomendasi karir yang ditargetkan dan strategi coaching yang dipersonalisasi.

🔧 Detail Algoritma K-Means

Fitur yang Digunakan untuk Clustering:
• Nilai Rata-Rata (IPK)
• Gaji (Gaji Bulanan)
• Lama Kerja Total (Total Pengalaman Kerja)

Langkah-Langkah Algoritma:
1. Standarisasi fitur menggunakan StandardScaler
2. Terapkan Metode Elbow untuk menemukan k optimal (1-10)
3. Latih K-Means dengan k={{ optimal_k }} cluster
4. Identifikasi centroid dan penugasan cluster
5. Visualisasikan hasil dalam ruang 2D

Inertia: Mengukur kepadatan cluster (nilai lebih rendah lebih baik)
